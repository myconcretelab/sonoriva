# SonoRiva 1.21.0

Publié le 13 septembre 2026.

Dans les paramètres d’un spectacle reçu en partage, **S’approprier le spectacle** crée un nouveau spectacle privé sous le nom choisi. Cette copie appartient uniquement à l’utilisateur qui la crée.

Les catégories, groupes, couleurs, sons, playlists et réglages sont repris avec des identifiants indépendants. Le spectacle original et ses partages restent inchangés. La copie subsiste après retrait du partage ou suppression de l’original.

Les fichiers audio et vidéo restent communs, sans stockage supplémentaire. La copie compte dans la limite de spectacles personnels du forfait. Les spectacles personnels peuvent également être renommés depuis les paramètres.
