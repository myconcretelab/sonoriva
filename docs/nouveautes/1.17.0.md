# SonoRiva 1.17.0

Date de publication : 6 septembre 2026.

## Notifications de souscription

Une notification est créée lorsqu’un compte active un forfait gratuit et lorsque Stripe confirme un nouvel abonnement payant ou un changement de forfait.

Le message indique le nom et le code du forfait, sa périodicité lorsqu’elle existe, le compte, le nom de l’utilisateur propriétaire et son adresse e-mail.

## Configuration

La rubrique **Notifications** du dashboard est accessible au rôle `super_admin`. Elle contient :

- l’activation des alertes e-mail et leur adresse destinataire ;
- l’activation des alertes Telegram ;
- le jeton du bot Telegram ;
- le `chatID` Telegram.

Le transport e-mail utilise la configuration SMTP ou Sendmail du serveur. Le jeton Telegram n’est pas renvoyé par l’API après son enregistrement. Le formulaire permet de le remplacer ou de le supprimer.

Les notifications sont identifiées en base afin qu’un événement de souscription déjà traité ne produise pas un nouvel envoi.
