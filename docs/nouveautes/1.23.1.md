# SonoRiva 1.23.1

9 novembre 2026.

Lors d’une préparation depuis le navigateur, un nouvel import rejoint les données et le journal du Bridge dans la même opération que son fichier. Une interruption ne laisse donc pas un import en attente d’envoi sans fichier natif.

Une copie peut reprendre lorsque les changements déjà transférés correspondent toujours à la source. Les changements propres à la régie locale continuent de bloquer leur remplacement.

Les imports déjà conservés dans le Bridge restent présents lors d’une préparation ultérieure, même lorsque le navigateur ne possède pas leurs fichiers. L’indicateur de disponibilité inclut ces imports natifs.

Cette correction est publiée avec l’interface indépendante. Elle fonctionne avec Bridge 1.1.0 et ne nécessite pas de nouvelle compilation native.
